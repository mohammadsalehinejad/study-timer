ساخت APK بدون نصب Android Studio (با GitHub، رایگان)

۱) در github.com یک حساب بساز و یک مخزن (Repository) جدید بساز (مثلاً study-timer).
۲) کد HTML برنامه‌ات را در فایل  src/index.html  جایگزین کن (همین فایلی که فرستادی، بدون تغییر).
۳) همهٔ محتویات این پوشه (شامل پوشهٔ مخفی .github) را در مخزن آپلود کن:
   در صفحهٔ مخزن: Add file ← Upload files ← کشیدن و رها کردن همه‌چیز ← Commit changes.
   (اگر پوشهٔ .github آپلود نشد، فایل .github/workflows/build-apk.yml را با Add file ← Create new file دستی بساز و محتوایش را کپی کن.)
۴) به تب Actions برو. ساخت خودکار شروع می‌شود (۳ تا ۸ دقیقه).
۵) بعد از تیک سبز، روی آن اجرا کلیک کن و پایین صفحه در بخش Artifacts فایل  study-timer-apk  را دانلود کن.
۶) فایل zip را باز کن؛ داخلش app-debug.apk است. آن را به گوشی بفرست و نصب کن
   (اگر اندروید هشدار داد، «نصب از منابع ناشناس» را برای همان برنامهٔ فایل‌منیجر فعال کن).

بعد از هر تغییر در src/index.html، دوباره آپلود کن تا APK جدید ساخته شود.
